## 🚀 Featured Project

### 📊 Berlin Short-Term Rental Market Analysis
My data analytics capstone — an end-to-end analysis of Berlin's Airbnb market using real data from Inside Airbnb (14,274 listings).

- Cleaned and prepared the raw data in Python (pandas), handling messy prices, missing values, and outliers with documented decisions
- Explored pricing, occupancy, and guest satisfaction across Berlin's districts
- Answered three business questions in SQL (PostgreSQL)
- Prepared KPI tables for a Tableau dashboard
- Key finding: superhosts achieve roughly 3× the occupancy of regular hosts

**Tools:** Python (pandas, matplotlib), PostgreSQL, Tableau, Jupyter, Git

🔗 [View the project](https://github.com/antonio-schmidtgen/berlin-short-term-rental-market-analysis)
